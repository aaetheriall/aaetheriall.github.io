01 / BEHIND IT ALL
CORE 001THE BACKEND

Fleasion:

Fleasion replaces Roblox game assets in real time on Windows, macOS and Linux (Sober). It runs a local proxy between Roblox and its servers, so you can swap textures, audio, meshes, animations and other assets before they reach the game client. It is what powers the skin changer.

02 / WHAT MAKES IT WORK
UNIT 002THE MAGIC

The config:

It tells fleasion WHAT to change. It's how the skins change!

It is a JSON file that contains a list of asset IDs and their replacements. Completely open-source, just like fleasion.
